Versión corta — 3 slides para LinkedIn

Cover · El giro · Closer. Cada .slide mide exactamente 1080×1350px.

  1. Zoom del browser al 100% (Ctrl + 0).
  2. Capturá con Win + Shift + S (selección rectangular) desde la esquina del slide.
  3. O DevTools (F12) → device mode → 1080×1350 → "Capture full size screenshot".
  4. Subí las 3 imágenes a LinkedIn como carrusel, en orden.
